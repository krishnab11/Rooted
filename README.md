# 🌱 Rooted – Your Smart Gardening Assistant

Rooted is an AI-powered gardening recommendation system built with **Streamlit**.  
It helps users choose the best plants based on climate, care tips, and growth requirements.

**Live Demo** → [Open Rooted App](https://krishnab11-rooted-app-eozktx.streamlit.app/#gardening-recommendations)

---

## 📌 Features
- **Plant Recommendations** based on location & weather conditions
- **Gardening Tips** for plant care, watering, and sunlight needs
- **Searchable Plant Database** powered by CSV data
- **Simple Web UI** built with Streamlit
- Works directly in your browser — no installation required!

---

## 🛠️ Tech Stack
- **Python 3.8+**
- **Streamlit**
- **Pandas**
- **CSV Dataset** (plant_data.csv)
